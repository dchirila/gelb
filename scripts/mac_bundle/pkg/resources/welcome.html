This installs GeLB @VERSION@ for macOS on Apple Silicon into your home folder, at ~/gelb. No administrator password is needed and nothing is installed system-wide.

The package carries everything GeLB needs: the compiler gelbc, the compile-and-run wrapper gelb-run, the viewer gelb-view, all examples, the user tutorial, the VS Code extension, a private Python with every package, and the OpenMP, HDF5 and NetCDF libraries. The one thing it uses from your Mac is the C++ compiler that comes with Xcode (or the Command Line Tools).

On the Installation Type page you choose which shell(s) should find the GeLB commands (zsh, bash, tcsh) and whether to install the VS Code extension. Your login shell is preselected.
