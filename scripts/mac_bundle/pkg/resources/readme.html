What the installer does

  1. Copies GeLB to ~/gelb (an existing ~/gelb is kept as ~/gelb.bak-<date>).
  2. For each shell you tick, appends one PATH line to that shell's startup file: ~/.zprofile, ~/.bash_profile (or ~/.profile), ~/.tcshrc (or ~/.cshrc). Running the installer again never adds the line twice.
  3. Writes ~/gelb/.vscode/settings.json and, if ticked and VS Code is installed, installs the GeLB extension.
  4. Compiles and runs one example as a check (20 to 40 seconds) and writes ~/gelb/INSTALL_REPORT.txt. If the check fails, that report opens by itself and says what to do.

Afterwards

Open a new Terminal window and try:

gelb-run -n 1000 -w 100 --view ~/gelb/examples/lbm/2d/taylor_green_vortex_2d_bgk.gelb

The guide is ~/gelb/START_HERE.md; the manual is in ~/gelb/docs/html/index.html.

Installing from Terminal instead

installer -pkg "GeLB-@VERSION@.pkg" -target CurrentUserHomeDirectory

configures your login shell; installer -showChoicesXML and -applyChoiceChangesXML change the choices.

Uninstall

Delete ~/gelb and the two GeLB lines the installer added to your shell startup file; remove the extension from VS Code's Extensions view.
