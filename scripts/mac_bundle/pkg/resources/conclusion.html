GeLB @VERSION@ is installed in ~/gelb.

The installer compiled and ran one example. If that check failed, a window with ~/gelb/INSTALL_REPORT.txt has opened and explains what to do (usually: install Xcode or the Command Line Tools, or accept the Xcode license). The report is written in every case.

Open a new Terminal window (the PATH change applies to new windows only), then try:

gelb-run -n 1000 -w 100 --view ~/gelb/examples/lbm/2d/taylor_green_vortex_2d_bgk.gelb

The guide is ~/gelb/START_HERE.md.
