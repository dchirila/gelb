=================================
GeLB documentation
=================================

Welcome to the documentation of **GeLB**, a domain-specific
language and compiler for Lattice Boltzmann simulations.

:doc:`usrman` is a guided tutorial for GeLB users who want to write
and run simulations.  No prior compiler or Fortran experience is
required.

:doc:`devman` is a short manual for contributors to the compiler:
the repository map, the compilation pipeline, the backends, and
checklists for extending GeLB.

The project homepage is `gelb-lang.org <https://gelb-lang.org>`_;
the source code lives at
`github.com/dchirila/gelb <https://github.com/dchirila/gelb>`_.
