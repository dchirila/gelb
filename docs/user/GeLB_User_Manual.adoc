GeLB is a domain-specific programming language (DSL), which allows you to
quickly create numerical simulations based on the lattice Boltzmann (LB) method,
by writing a high-level description of your simulation. In essence, GeLB
consists of:

. the specification of the DSL, and
. support tools for the DSL (reference compiler, editor/IDE plugins, etc.)

This manual focuses on the basic knowledge required for _users_ of the software,
to: 

. write their simulations (in `.gelb` files),
. compile the `.gelb` files into executable programs, and
. execute the simulations on their target machines.

If you want to contribute to GeLB, we recommend to: 

. **First**, familiarize yourself with the basic concepts of GeLB, by reading
this manual.
. Read the link:../dev/ARCHITECTURE.md[ARCHITECTURE.md] file, to get a
high-level overview of how GeLB works under the hood.
. Read the link:../dev/GeLB_Developer_Guide.adoc[GeLB Developer's Guide], for
more developer-oriented information.
