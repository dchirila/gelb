GeLB is a domain-specific programming language (DSL), which allows you to
quickly create numerical simulations based on the Lattice Boltzmann (LB)
method, by writing a high-level description of your simulation.

Features:
- easy to learn
- easy to debug (due to many built-in correctness & validation checks)
- high performance (*almost* for free)
- open-source and extensible
